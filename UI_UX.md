# Field interface

Rows is a first-level destination beside Today, People, History and Settings. The existing Settings entry and team-specific entry remain available. A team entry retains its team context; the global Rows destination returns to the shared row workspace.

The workspace has one compact field selector and search field, with keyboard submission, visible applied filters and a clear action. Search covers row numbers, row types, source string IDs and post IDs. An exact row number is ranked first. Fields follow the configured order. The list initially renders 60 rows, offers more rows in batches of 60 and resets the batch after filtering. Loading another batch focuses the first new row for keyboard continuity.

List and Map share the selected field and search. Administrative tools are below the work area in a disclosed Row tools section. Viewer accounts retain the existing restrictions; editor actions remain guarded by the same application and server permissions.

A row card leads with field, review status, panel identity, panel count, damper count and motor position. Instructions, Panels, Dampers and Pallets are directly selectable. Instructions keep panel ranges, polarity, type markers and drive-gap warnings visible; string IDs, full type descriptions and original markings are available in Panel IDs & markings. Damper post IDs and motor post IDs remain available. Source notes and the editor entry follow the working information.

The map retains independent Row plan and Satellite views. My position, Follow me, Stop location and the location status precede the map surface. A selected row appears in a compact card over the map, with counts, ordered polarity chips, motor position and direct Open row / Pallets actions. IDs and full panel identities expand inside the card. The card can be closed and does not capture map gestures outside its bounds. Google attribution remains clear, including its responsive copyright rows; Google's zoom controls appear at the top right above the row card. Enabling My position or Follow me closes the row card so the device marker stays visible. Loading and authorization errors, stale or denied location, accuracy, and the unconfirmed coordinate-system notice remain explicit. Help and privacy details are disclosed separately. Satellite GPS remains independent of source-coordinate confirmation; row overlays never assume a coordinate system.

The Panels scheme combines groups, polarity, motor and dampers. Source post coordinates are projected along the source row axis only when the group ranges and panel count match the current plan. Without matching source positions, damper buttons and the separate Dampers scheme remain available; no post positions are invented. SVG elements and corresponding large buttons open the original IDs, full Description / Current Class and installation notes. Keyboard users can activate SVG elements with Enter or Space and return from the details panel.

Pallets includes Driver view: a full-viewport screen with a fixed row header and label-direction reminder, a scrollable enlarged scheme, pair selector and pallet total. Back returns to the same pair in Pallets. The main navigation is omitted while Driver view is open. This works for viewers and performs no shared-data writes.

The Rows hub offers Continue where you left off after opening a row. Only its row-plan ID is saved in local browser storage. Deleted or unavailable rows do not produce a resume shortcut; disabled storage does not prevent browsing. The shortcut is local to that browser and never stores GPS fixes or synchronizes users' viewing history.

The interface uses the existing colour system and semantic controls. Main navigation, section controls, map controls and disclosure targets are at least 44 CSS pixels high. Source details remain keyboard accessible. Reduced-motion preferences are preserved. No new imagery, font downloads or UI dependencies are added; Google Maps still loads on demand.

This update does not change installation calculations, palette assignments, row specifications, team membership, authentication or database data. Pallet labels still follow the positive connector, capacity is 36, carryover is excluded and paired rows align at their motors.
