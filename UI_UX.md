# Field interface

Rows is a first-level destination beside Today, People, History and Settings. The existing Settings entry and team-specific entry remain available. A team entry retains its team context; the global Rows destination returns to the shared row workspace.

The workspace has one compact field selector and search field, with keyboard submission, visible applied filters and a clear action. Search covers row numbers, row types, source string IDs and post IDs. An exact row number is ranked first. Fields follow the configured order. The list initially renders 60 rows, offers more rows in batches of 60 and resets the batch after filtering. Loading another batch focuses the first new row for keyboard continuity.

List and Map share the selected field and search. Administrative tools are below the work area in a disclosed Row tools section. Viewer accounts retain the existing restrictions; editor actions remain guarded by the same application and server permissions.

A row card leads with field, review status, panel identity, panel count, damper count and motor position. Instructions, Panels, Dampers and Pallets are directly selectable. Instructions keep panel ranges, polarity, type markers and drive-gap warnings visible; string IDs, full type descriptions and original markings are available in Panel IDs & markings. Damper post IDs and motor post IDs remain available. Source notes and the editor entry follow the working information.

The map retains independent Row plan and Satellite views. My position, Follow me, Stop location and the location status precede the map surface. Loading and authorization errors, stale or denied location, accuracy, and the unconfirmed coordinate-system notice remain explicit. Help and privacy details are disclosed separately. Satellite GPS remains independent of source-coordinate confirmation; row overlays never assume a coordinate system.

The interface uses the existing colour system and semantic controls. Main navigation, section controls, map controls and disclosure targets are at least 44 CSS pixels high. Source details remain keyboard accessible. Reduced-motion preferences are preserved. No new imagery, font downloads or UI dependencies are added; Google Maps still loads on demand.

This update does not change installation calculations, palette assignments, row specifications, team membership, authentication or database data. Pallet labels still follow the positive connector, capacity is 36, carryover is excluded and paired rows align at their motors.
